# 메일 연결

브리핑과 채팅에서 "최근 받은 메일 중 답장이나 조치가 필요한 것"을 챙깁니다. 연결하는 방법은 두 가지입니다.

| 모드 | 어떻게 읽나 | 뇌 |
|---|---|---|
| `imap` | 메일 주소와 앱 비밀번호로 시사가 받은편지함을 직접 읽습니다(읽기 전용) | 어떤 뇌든 됩니다(Gemini·OpenAI·Claude API·Codex·Claude Code). AI 없이 쓰면 메일만 가져오고 할 일로 뽑지는 않습니다 |
| `mcp` | Claude Code에 등록한 메일 MCP 서버의 읽기 도구로 읽습니다 | Claude Code 뇌일 때만 |
| `off` | 브리핑에서 메일 단계가 빠집니다(기본) | |

## 쉬운 방법: 앱 비밀번호로 연결하기(`imap`)

패널의 설치 탭 「더 연결하기」에 있는 **메일(앱 비밀번호)** 카드에서 서비스를 고르고, 메일 주소와 비밀번호를 넣고 **연결**을 누르면 됩니다. 주소를 적으면 서비스(Gmail·네이버·다음)는 알아서 골라 둡니다. 연결을 누르면 시사가 그 자리에서 로그인해 받은편지함을 열어 보고, 되면 저장합니다. 안 되면 아무것도 저장하지 않고 이유를 알려 줍니다.

시사는 메일을 읽기만 합니다.

- 받은편지함을 읽기 전용(IMAP `EXAMINE`)으로 엽니다. 서버가 읽기 전용으로 열어 주지 않으면 아무것도 읽지 않습니다.
- 메일 구조(`BODYSTRUCTURE`)를 먼저 보고 글 본문 부분(text/plain·text/html)만 `BODY.PEEK[n]`으로 받습니다. 본문은 자르지 않고 그 부분 전체를 받습니다. 첨부 파일은 내용을 받지 않고 이름과 크기만 적어 둡니다. 그래서 큰 첨부가 붙은 메일도 금방 읽습니다. 읽음 표시가 바뀌지 않습니다. 글자 본문(HTML 메일은 글자만)을 이 컴퓨터의 `cy.db`에 두고, 24시간이 지난 메일은 지웁니다.
- 메일 보내기(SMTP), 지우기, 옮기기, 라벨·플래그 바꾸기 코드는 없습니다.
- 최근 24시간에 받은 메일을 전부(개수 제한 없이) 15분마다, 그리고 브리핑 직전에 가져옵니다. 메일마다 보낸 사람, 제목, 받은 때, 본문 앞부분(HTML 메일은 글자만)을 모델에 넘깁니다.
- 채팅에서 특정 메일을 말하면 그 메일의 **전체 본문**을 넘깁니다. 보낸 사람 이름이나 주소, 제목 낱말을 말하거나(「정동기·장현영 메일 표로」), 「그거 원문」「자세히」처럼 바로 앞 답에 나온 메일을 가리키면 됩니다. 「메일 보여줘」처럼 가리키는 메일이 없으면 본문 앞부분 목록만 넘깁니다. 「전부 자세히」「모든 메일 본문」처럼 다 달라고 하면 전부 넘깁니다. 어떤 뇌든 됩니다. Claude Code 뇌는 `mail_read` 도구로도 읽습니다.
- 몇 통이든 넘기지만, 한 번에 모델에 다 넣을 수 없을 만큼 길면 앞에서부터 한 묶음만 넣고 나머지는 나눠서 넣습니다. 시사가 「나눠서 보여 드려요」라고 말하면, 같은 대화에서 「나머지」「이어서」라고 하면 다음 묶음이 들어갑니다. 아주 긴 메일 한 통도 이렇게 나눠 읽습니다.
- 연결 해제나 계정 빼기를 하면 저장해 둔 본문도 지웁니다.
- 비밀번호는 이 컴퓨터의 `~/.cy-agent/config.json`(권한 600)에만 저장합니다. 설정 창·연결 상태·로그·도움 보내기에는 나오지 않습니다. 파일에 두기 싫으면 환경변수 `CY_AGENT_MAIL_PASSWORD`로 줄 수도 있습니다.

### Gmail

1. Google 계정에 [2단계 인증](https://myaccount.google.com/signinoptions/twosv)을 켭니다. 앱 비밀번호는 2단계 인증이 켜져 있어야 만들 수 있습니다.
2. [앱 비밀번호](https://myaccount.google.com/apppasswords) 화면에서 이름(예: 시사)을 적고 만듭니다.
3. 나온 16자리를 카드의 **앱 비밀번호** 칸에 붙여 넣습니다. 띄어쓰기는 있어도 됩니다. Google 계정 비밀번호는 넣지 않습니다.

프로모션·소셜 탭의 메일은 서버 검색(`X-GM-RAW`)에서 빼고 읽습니다. 메일 줄에는 Gmail에서 그 메일을 여는 링크가 붙습니다.

앱 비밀번호 메뉴가 안 보이면 2단계 인증이 꺼져 있거나, 회사·학교 계정이라 관리자가 막은 경우입니다. 회사 계정이 막혀 있으면 관리자에게 묻거나 개인 계정을 씁니다.

### 네이버 메일

1. 네이버 메일 **환경설정 → POP3/IMAP 설정**에서 **IMAP/SMTP 사용**을 **사용함**으로 켭니다.
2. 2단계 인증을 쓰면 **네이버 내정보 → 보안설정 → 2단계 인증 → 애플리케이션 비밀번호 관리**에서 비밀번호를 만들어 넣습니다. 2단계 인증을 안 쓰면 네이버 비밀번호로 로그인됩니다.

서버는 `imap.naver.com:993`(TLS)입니다. 네이버에는 Gmail 같은 카테고리 거르기가 없어서 모두 가져옵니다. 광고·뉴스레터로 보이는 메일(`List-Unsubscribe` 머리말, noreply 보낸 사람 등)은 표시만 해 두고, 할 일로 만들지는 모델이 거릅니다.

### 다음 메일

1. 다음 메일 **환경설정 → IMAP/POP3**에서 **IMAP 사용**을 켭니다.
2. 2단계 인증을 쓰면 카카오계정 보안 설정에서 만든 앱 비밀번호를 넣습니다.

서버는 `imap.daum.net:993`(TLS)이고 `@daum.net`·`@hanmail.net` 주소에 씁니다. 카카오메일(`@kakao.com`)은 서버 주소를 확인하지 못해 자동으로 고르지 않습니다. 카카오 안내에서 IMAP 서버 주소를 확인한 뒤 「다른 메일(IMAP)」로 넣습니다.

### 다른 메일(IMAP)

「다른 메일(IMAP)」을 고르고 IMAP 서버 주소와 포트(보통 993)를 적습니다. 연결은 늘 TLS로 합니다.

### 메일 계정 여러 개

메일 계정은 몇 개든 붙일 수 있습니다. 회사 Gmail과 개인 네이버 메일처럼 서비스가 달라도 됩니다.

- 계정을 하나 연결하면 카드 위쪽에 **연결된 계정 목록**이 생깁니다. 줄마다 서비스, 주소, 가져온 메일 수(못 가져왔으면 그 이유)와 **빼기** 버튼이 있습니다.
- 다른 계정은 목록 아래 **＋ 다른 메일 계정 추가**를 눌러 같은 폼으로 넣습니다. 연결되면 목록에 붙고 폼은 비워집니다.
- 이미 붙인 주소를 다시 넣으면 새 계정을 만들지 않고 그 계정의 비밀번호를 바꿉니다. 앱 비밀번호를 새로 만들었을 때 이렇게 바꿉니다.
- **빼기**는 그 계정의 비밀번호와 가져온 메일만 지웁니다. 마지막 계정을 빼면 메일 연결이 꺼집니다. 모든 계정을 한 번에 끊으려면 **연결 해제**를 누릅니다.
- 계정마다 따로 가져옵니다. 한 계정이 실패해도 나머지 계정의 메일은 그대로 들어옵니다. 실패한 계정은 전에 가져온 메일을 남겨 둡니다(24시간이 지난 것은 뺍니다).
- 비밀번호가 틀렸거나 IMAP이 꺼져 있는 등 로그인 자체가 거절되면, 그 계정은 다시 연결할 때까지 자동으로 다시 로그인하지 않습니다. 같은 비밀번호로 계속 로그인하면 메일 서비스가 계정을 잠그거나 의심 로그인으로 막을 수 있어서입니다. 카드에 「다시 연결해 주세요」가 보이면 같은 주소와 새 비밀번호를 넣어 다시 연결합니다.
- 인터넷이 끊기거나 서버가 답하지 않으면 정기 가져오기 간격을 15분, 30분, 1시간, 2시간, 4시간으로 늘립니다. 한 번 되면 다시 15분마다 가져옵니다. 브리핑 직전에는 간격과 상관없이 가져옵니다.
- 설정 창 「연결 상태」의 메일 줄은 「메일 2개 계정 · 최근 메일 N통」처럼 보입니다. 일부 계정만 못 가져오면 주황색으로 바뀌고 「주소: 이유」가 붙습니다. 모두 못 가져오면 빨간색입니다.
- 브리핑과 채팅에 넘기는 메일 줄마다 받은 계정(받는 주소)을 적습니다. 그래서 「회사 메일로 온 것만」처럼 물어볼 수 있습니다.

### 설정 파일 모양

카드가 저장하는 값은 이렇습니다. 손으로 써도 되고, 그다음 데몬을 다시 켭니다.

```json
{
  "connectors": {
    "mail": {
      "mode": "imap",
      "accounts": [
        { "id": "work", "preset": "gmail", "user": "me@gmail.com", "password": "앱 비밀번호" },
        { "id": "home", "preset": "naver", "user": "me@naver.com", "password": "비밀번호" }
      ]
    }
  }
}
```

| 키 | 기본값 | 설명 |
|---|---|---|
| `accounts` |  | 계정 목록. 개수 제한은 없습니다. 같은 주소는 한 번만 씁니다 |
| `accounts[].id` | 주소로 만듦 | 계정 이름(영문·숫자·`-`·`_`). 빼기에 씁니다 |
| `accounts[].preset` | 주소로 짐작, 모르면 `custom` | `gmail` · `naver` · `daum` · `custom` |
| `accounts[].user` |  | 메일 주소 |
| `accounts[].password` |  | 앱 비밀번호(또는 서비스 비밀번호). 환경변수 `CY_AGENT_MAIL_PASSWORD`는 첫 계정 비밀번호로 쓰고 파일보다 먼저입니다 |
| `accounts[].host` / `port` | `custom`만 · 포트 993 | IMAP 서버 |
| `sinceHours` | `24` | 몇 시간 전까지 받은 메일을 읽을지(모든 계정) |
| `skipPromotions` | `true` | Gmail 프로모션·소셜 탭을 뺄지(모든 Gmail 계정) |

예전 한 계정 모양(`"mail": { "mode": "imap", "preset": "gmail", "user": "…", "password": "…" }`)도 그대로 읽습니다. 계정 하나로 보고, 카드에서 계정을 더하거나 바꾸면 위의 새 모양으로 저장합니다.

### 연결이 안 될 때

연결을 누르면 그 자리에서 이유가 보이고, 연결한 뒤에는 카드의 계정 목록과 설정 창 「연결 상태」의 메일 줄에 계정마다 가져온 메일 수나 마지막 실패 이유가 보입니다.

| 보이는 말 | 확인할 것 |
|---|---|
| 메일 주소나 비밀번호가 맞지 않아요 | Gmail은 Google 계정 비밀번호가 아니라 앱 비밀번호 16자리인지, 네이버·다음은 IMAP 사용을 켰는지와 2단계 인증이면 앱(애플리케이션) 비밀번호인지 봅니다 |
| Google 계정 비밀번호로는 연결할 수 없어요 | 2단계 인증을 켜고 앱 비밀번호를 만들어 넣습니다 |
| IMAP 이 꺼져 있어요 | 메일 설정에서 IMAP을 켭니다. 회사·학교 계정이면 관리자가 막았을 수 있습니다 |
| 이 로그인을 잠시 막았어요 | 브라우저에서 그 메일에 한 번 로그인해 보안 알림을 확인한 뒤 다시 합니다 |
| 회사·학교 계정 관리자가 막아 두었어요 | 관리자에게 묻거나 개인 계정을 씁니다 |
| 서버가 답하지 않았어요 · 연결하지 못했어요 | 인터넷, VPN, 회사 방화벽을 봅니다 |
| 보안 인증서를 확인하지 못했어요 | 회사 네트워크나 백신의 메일·HTTPS 검사가 연결을 가로채는지 봅니다. 윈도우 백신(예: 메일 보호, SSL 검사)이면 그 검사에서 시사를 예외로 넣습니다 |

## MCP로 연결하기(`mcp`, 고급)

MCP 모드에서는 메일을 로컬에 모아 두지 않습니다. 브리핑이나 더블클릭 채팅 때 Claude Code 뇌가 매핑된 읽기 도구(`search`·`read`)로 그때그때 읽습니다.

발송·삭제·라벨 변경 같은 쓰기 도구는 서버에 있어도 쓰이지 않습니다. 허용 목록에는 매핑한 읽기 도구만 들어가고, 쓰기 이름은 훅이 막습니다(`agent/src/guard.ts`).

### 프리셋 `gmail`: [GongRzhe/Gmail-MCP-Server](https://github.com/GongRzhe/Gmail-MCP-Server)

> 이 저장소는 2025년 8월부터 보관(archived) 상태라 더 이상 고쳐지지 않습니다(2026-10 확인). 오래 쓰실 거라면 다른 Gmail MCP를 아래 "직접 채우기"로 붙이는 편이 낫습니다.

1. [Google Cloud Console](https://console.cloud.google.com/) → 프로젝트 만들기 → **Gmail API** 사용 설정
2. OAuth 동의 화면 → 테스트 사용자에 내 이메일 추가
3. API 및 서비스 → 사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 유형 **데스크톱 앱**(또는 웹 애플리케이션 + 리디렉션 URI `http://localhost:3000/oauth2callback`) → JSON 내려받기
4. 파일 이름을 `gcp-oauth.keys.json`으로 바꿔 `~/.gmail-mcp/`에 둡니다.
   ```bash
   mkdir -p ~/.gmail-mcp && mv ~/Downloads/client_secret_*.json ~/.gmail-mcp/gcp-oauth.keys.json
   ```
5. 인증합니다(브라우저가 열리고, 토큰은 `~/.gmail-mcp/`에 저장됩니다).
   ```bash
   npx @gongrzhe/server-gmail-autoauth-mcp auth
   ```
6. 등록:
   ```bash
   claude mcp add --scope user --transport stdio gmail -- npx -y @gongrzhe/server-gmail-autoauth-mcp
   ```
7. 설정:
   ```json
   { "connectors": { "mail": { "mode": "mcp", "preset": "gmail" } } }
   ```

매핑: `search` → `search_emails`, `read` → `read_email`.

### 프리셋 `ms-365`: [Softeria/ms-365-mcp-server](https://github.com/Softeria/ms-365-mcp-server)

캘린더와 같은 서버를 함께 쓸 수 있습니다([calendar.md](calendar.md#프리셋-ms-365-softeriams-365-mcp-server)). 이미 등록했다면 1·2단계는 건너뛰세요.

```bash
npx -y @softeria/ms-365-mcp-server --login
claude mcp add --scope user --transport stdio ms365 -- npx -y @softeria/ms-365-mcp-server --read-only
# 회사·학교 계정이면 두 명령 끝에 --org-mode
```

```json
{ "connectors": { "mail": { "mode": "mcp", "preset": "ms-365" } } }
```

매핑: `search` → `list-mail-messages`, `read` → `get-mail-message`(출처: 저장소 `src/endpoints.json`).

### 다른 메일 MCP: 직접 채우기

```json
{ "connectors": { "mail": { "mode": "mcp", "server": "<등록한 이름>", "tools": { "search": "<메일 검색/목록 도구>", "read": "<메일 하나 읽기 도구>" } } } }
```

`tools`를 비우면 서버 전체가 허용되고, 가드가 읽기 이름(get·list·search·read …)만 통과시킵니다.
